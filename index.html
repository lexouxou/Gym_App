⚙️ Données & Sauvegardes

Toutes tes données sont stockées directement sur ton téléphone (localStorage). Aucun compte n'est requis, et ça fonctionne 100% hors-ligne dans la salle.

🚀 Prêt pour GitHub Pages

Pour l'avoir sur ton smartphone comme une vraie application sans rien installer :

  1. Pousse ce code sur ton dépôt GitHub Gym_App.
  2. Dans GitHub : Settings > Pages > Source: Deploy from branch (main).
  3. Ouvre l'URL sur Safari ou Chrome sur ton mobile, puis clique sur "Ajouter à l'écran d'accueil" !
